# Personal Analytics Platform - Landing Page

A premium, enterprise-grade landing page for the Personal Analytics Platform - a revolutionary self-monitoring application that combines sleep recording, AI-powered insights, and comprehensive lifestyle correlation analysis.

## 🏛️ Design Philosophy

This landing page embodies **royal/masonic luxury design** with:

- **Deep Purple & Gold Color Palette**: Sophisticated royal purples (#8b3df7) combined with luxury gold (#f0b824)
- **Premium Typography**: Playfair Display for headings, Inter for body text
- **Enterprise-Grade UI**: Professional glassmorphism effects, subtle animations, and premium gradients
- **Luxury Visual Elements**: Crown icons, sophisticated patterns, and royal symbolism

## 🚀 Technology Stack

- **Next.js 15** with App Router
- **TypeScript** for type safety
- **Tailwind CSS** with custom luxury design system
- **Framer Motion** for smooth animations
- **Lucide React** for premium icons
